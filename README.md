# מי אמר את זה?
משחק מסיבה מהצ'אט של הקבוצה. האתר: https://mi-amar.pages.dev

- `index.html` – המשחק
- `app.js` – הקורא של צ'אט וואטסאפ, החיבור ל-Firebase וה-QR (נבנה מהקוד המקורי)
- `config.js` – הגדרות Firebase הציבוריות
- `firebase-rules.json` – כללי האבטחה של מסד הנתונים (מועתקים ידנית ל-Firebase)
